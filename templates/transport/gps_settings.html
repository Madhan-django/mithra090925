How GPS Integration Works
  • Any AIS-140 certified GPS device can send location data to this system.
  • Set the vehicle's GPS Device ID / IMEI in the vehicle record.
  • Configure your GPS device or Flespi gateway to HTTP POST to:
    {{ request.scheme }}://{{ request.get_host }}/transport/gps/push/
  • Payload format (JSON):
    {"device_id":"IMEI","lat":11.01,"lng":76.95,"speed":40,"heading":270,"timestamp":"2024-06-30T08:32:00Z"}
  • Mappls API key is required to display the live map.
