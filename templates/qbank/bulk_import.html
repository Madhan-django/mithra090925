How It Works

1
Download the template
Click "Download Template" to get the correct Excel format with all column headers pre-filled.
2
Fill in your questions
Add questions row by row. Class/Subject names must exactly match what's in the system.
3
Upload & import
Drop the file here and click Import. Questions are imported as Pending — review and approve in the bank.

Column Reference

All column headers are case-sensitive
Column Required? Accepted Values
class Yes Must match class name in system
subject Yes Must match subject name
question_type Yes MCQ / SHORT / LONG / FILL / TF / MATCH
question_text Yes The full question text
chapter Optional Must match chapter name
difficulty Optional EASY / MEDIUM / HARD
marks Optional Integer (default: 1)
tags Optional Space-separated tags
option_a / b / c / d MCQ only Option text for MCQ questions
correct_option MCQ only a / b / c / d
answer Optional Model answer text
explanation Optional Answer explanation text
